# ThoughtSpot + Snowflake Summit 2026 Hands-On Lab

A Next.js application for the ThoughtSpot hands-on lab at Snowflake Summit 2026.

## Installation

### Prerequisites

- [Node.js](https://nodejs.org/) 18 or later
- npm (included with Node.js)

### Clone and install

```bash
git clone https://github.com/thoughtspot/ts-snowflake-summit-2026.git
cd ts-snowflake-summit-2026
npm install
```

## Running the app

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Other commands

```bash
npm run build   # build for production
npm run start   # run the production build
npm run lint    # run ESLint
```
